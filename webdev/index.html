Where AI coding goes wrong on client work

  • It invents things that look right. Coding assistants guess WordPress hook names and function signatures from memory, and some of those hooks don't exist. The code reads fine until it runs on a client's site. (source)

  • "Done" doesn't always mean done. An assistant can report a fix that is still broken or a file that was never created, so you re-check everything yourself. (source)

  • Generated code isn't safe by default. In Veracode's 2025 study of more than 100 models, about 45% of the code samples failed security tests. On a client site, that's your name on the problem. (source)

What it won't touch

  • The live siteThe agent works on a local or staging copy only.
  • PublishingIt stops and leaves a note. You publish.
  • Your clients' inboxesIt drafts. You send.
  • Hooks it made upIt checks the real source or docs before using a function, and lists anything it couldn't verify.
  • "It's fixed, trust me"Every task ends with what changed and how to check it.

This lowers the risk. It doesn't remove it. You still review everything before it reaches a client.
