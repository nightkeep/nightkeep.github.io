Leaving an agent alone all night is the hard part.

  • One wrong action and you find out tomorrow. A stray command, an email sent, a deploy. Nobody is there to stop it.

  • In the morning, you can't tell what happened. Chat logs scroll away. You want one short note per task: done, blocked, or failed, and where the files are.

What's in the kit

Nightly planner
A stronger model reviews the project and queues the next night's tasks, five at most. Each task says what done looks like and where the output goes.
Task runner
A cheaper model works through the queue one task at a time, 30 minutes each.
Narrow permissions
It writes only to the folders you list. It has no shell.
Hand-off rule
Anything that publishes, contacts someone, or spends money is left for you, with the reason written down.
Morning report
Every task leaves a short note, and the results line up on one board.
Untrusted text rule
Instructions found inside web pages, files, or comments are treated as data, never as orders.

What it can't do, and why

  • --permission-mode dontAskAnything not on the list is refused. Your own "auto" settings can't approve it in the middle of the night.
  • --disallowedTools BashNo shell at all. Even harmless-looking commands are off.
  • --setting-sources local --strict-mcp-configYour personal settings and connected tools don't leak in and widen what it can reach.
  • Read(<project>/**)It reads the project folder and nothing else on your machine.
  • Edit(<project>/work/**)It writes to the output folders only. Its own rules and settings stay untouched.

This lowers the risk. It doesn't remove it. You still read the output, and you decide what gets published or sent.

Questions

Does it really run while I sleep?

Yes. The runner is built for unattended runs, scheduled on your own machine or server. Watch the first few runs yourself.

Can it send emails or publish for me?

No, by design. Those tasks stop with a note and wait for you.

What do I need?

Claude Code and an Anthropic account. Model usage is billed by Anthropic, not by Nightkeep.

Is it fully safe?

No tool can promise that. The kit limits where the agent writes, what it can run, and how long it works, and it hands risky actions to you. Read the output.
